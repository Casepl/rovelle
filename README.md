# Rovelle

Учебная основа для версионированного дерева файлов и доставки изменений.
Сейчас проект содержит библиотеку на C17 и командную утилиту `rovelle`.
Хранение файлов и сеть будут добавлены в следующих задачах.

План развития платформы и серии стримов описан в
[`docs/ROADMAP.md`](docs/ROADMAP.md).

Готовый план первого эфира находится в
[`docs/STREAM-01.md`](docs/STREAM-01.md).

## Сборка

Требуются компилятор C с поддержкой C17 и CMake 3.21 или новее.

```sh
cmake -S . -B build
cmake --build build
./build/rovelle --help
./build/rovelle version
```

`-S .` указывает каталог исходников, `-B build` — каталог для результатов
сборки. `cmake --build build` запускает компилятор через созданную CMake
конфигурацию. Папка `build` исключена из Git.

## Текущая структура

- `include/rovelle/` — публичные заголовки библиотеки.
- `src/` — реализация библиотеки.
- `cli/` — утилита командной строки.
- `CMakeLists.txt` — описание целей сборки и настроек компилятора.

## Правила будущего хранилища

1. Логический путь остаётся прежним, даже если содержимое файла меняется.
2. Опубликованная ревизия неизменяема.
3. Содержимое файла хранится отдельно от метаданных «путь → содержимое».

Центральный сервис будет хранить ревизии и журнал изменений. Агенты на
подах будут хранить локальный кеш файлов; центральная база на каждом поде
не нужна.

## Ошибки библиотеки

Функции библиотеки, которые могут завершиться неуспешно, будут возвращать
`rovelle_status_t` из `include/rovelle/status.h`. Значение `ROVELLE_OK` означает успех.
`rovelle_status_name()` превращает код в строку для диагностики.
