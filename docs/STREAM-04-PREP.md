# Подготовка к стриму 4

## За день или за несколько часов

- Прочитать `STREAM-04-JUNIOR-TASK.md` до раздела «Критерии готовности».
- Не писать реализацию заранее.
- Открыть `STREAM-04-CHEATSHEET.md` в Markdown Preview.
- Открыть `STREAM-04-RUNBOOK.md` на отдельной вкладке.
- Подготовить пустой Excalidraw и нарисовать только заголовки `blobs`,
  `manifest`, `revision`.
- Выключить посудомойку и другие постоянные источники шума.

## OBS

Использовать сцену с VS Code и камерой. Терминал должен занимать не меньше
четверти высоты окна, иначе команды и ошибки не читаются на телефоне.

В OBS открыть:

```text
View → Docks → Custom Browser Docks
```

Добавить:

```text
Dock Name: Twitch Chat
URL: https://www.twitch.tv/popout/caseplink/chat?popout=
```

Поставить dock справа от preview. Чат не попадёт в трансляцию, но останется
перед глазами и не выключится вместе с телефоном.

Сцены и горячие клавиши:

```text
Ctrl+1  Stream
Ctrl+2  Code Clean
Ctrl+3  Excalidraw
Ctrl+4  Отошёл
```

Перед эфиром записать 20 секунд речи, послушать в наушниках и проверить:

- голос обычно находится около `-18 ... -10 dB`;
- нет постоянного бытового гула;
- начало слов не обрезается noise gate;
- клавиатура тише голоса.

## Экран и приватность

Из корня проекта выполнить:

```sh
export PATH="$PWD/tools:$PATH"
rbuild
```

Проверить, что в выводе нет `/Users/<username>`.

Использовать Window Capture для VS Code. Закрыть уведомления, почту, Telegram,
историю терминала и вкладки с личными данными.

## За 10 минут

- Запустить OBS и открыть Twitch Chat dock.
- Проверить нужный микрофон и движение индикатора.
- Проверить запись на дорожках 1, 2 и 3.
- Открыть корень `rovelle` в терминале.
- Увеличить шрифт редактора и терминала до читаемого размера.
- Положить рядом воду.
- Проговорить хук один раз без записи.

## После эфира

- Сохранить VOD локально.
- Запустить Whisper для расшифровки.
- Отдельно записать чистый дубль финальной демонстрации для шортса.
- Выбрать шортс только после проверки, что он понятен без полного стрима.
